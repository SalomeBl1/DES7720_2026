### Reveal image

en jouant avec quelques paramètres, je suis tombée par surprise sur une façon de révéler l'image. 
Je pars sur une base de BG noir. Dans draw, je recommence par un fond noir puis une copie de l'image, et dans un frame de 100 par 100 qui bouge avec la souris, la copie de l'image se révèle.
